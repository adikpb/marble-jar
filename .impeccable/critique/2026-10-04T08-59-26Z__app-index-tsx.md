## Overall Impression

The world is authored and the loop is honest; the first run is where it strains. Biggest opportunity: make the first marble inevitable — one tag language, one visible first step, and a header that stays espresso on web.

## What's Working

- Operable checklist, not a tour: rows focus real fields / deep-link the real jar and tick from real data — onboarding as doing, never desynced.
- Paper-vs-chrome material split: slips the only light objects; life-vs-room legible without explanation.
- Honest removals as first-class marks: ghost −Broke one, open ring, darkened struck slip. Emptying the jar feels safe, per product principles.

## Priority Issues

1. **[P0] Two tag-picker languages for one choice.** Shelf beads (hue-as-border) vs jar flooded rows (hue-as-fill) force relearning the primary action. Fix: unify on flooded TagField everywhere; shelf beads become compact flooded pills. Suggested command: `clarify`.
2. **[P1] Web header paints light gray, not espresso.** Header container renders #F2F2F2 with ink title on top; configured `Lamp.ground` absent from DOM. Breaks the Espresso rule on web. Fix: trace why `headerStyle` is dropped on web and restore it. Suggested command: `audit`.
3. **[P1] First-run stack buries the first step.** Checklist + add-row + fully interactive composer compete; composer fails with "add someone first" on the happy path. Fix: collapse composer to a preview until `hasPerson`, expand with settle ease on add. Suggested command: `onboard`.
4. **[P1] 7-way tag choice with no scent.** Equal-weight beads stall BRAVING-newcomers; gloss only after tap; guide vanishes if a jar is added fast. Fix: show guide until first tagged marble + persist last-used tag as soft default. Suggested command: `distill`.
5. **[P2] Shelf order fights stated order-of-use.** Add-row jumps position by `isFirstRun`; search sits below the fold. Fix: single add-row position above search; lower checklist margin so it doesn't push the composer down. Suggested command: `layout`.
6. **[P3] Destructive remove has no undo.** Confirm copy is honest but final; local-only means gone is gone. Fix: 5s undo line after confirm before refresh settles. Suggested command: `harden`.

- **Casey (returning, 3 jars, bedtime log):** picker row grows into an unscannable wall of pills; re-chooses from 7 beads nightly with no recent-tag memory.

## Minor Observations

- Week-ribbon slips lack the `+1/−1` sequence numbers jar slips carry — why the asymmetry?
- `sortOn` fills ink while `pickOn` fills cherry — will users read a cherry pick as "this changes data"?
- Checklist rows look like todos (checkbox dots) but focus fields — risk of feeling tricked on first tap.
